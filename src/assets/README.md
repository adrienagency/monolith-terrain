# Modèles 3D embarqués

## steamer.glb — vapeur SS Norrtelje

Source : modèle « SS Norrtelje low-poly », acquis par Adrien sur Fab (Epic
Games Marketplace), sous **Fab End User License Agreement**.

Optimisé pour une vue LOINTAINE : 2,69 Mo → 112 Ko (meshopt + textures WebP
128², simplification 1 %). 5 577 triangles.

⚠️ RAPPEL DE LICENCE, signalé à Adrien le 2026-07-26 et assumé par lui :
le §5(a) du contrat Fab interdit de distribuer le Contenu « sur une base
autonome », et le §4(c) impose de « restreindre l'extraction du Contenu hors
du Projet ». Un fichier servi depuis une URL publique ne restreint rien. Le
fichier vit donc sous `src/` et NON sous `public/` : Vite l'émet en asset
haché dans le bundle, ce qui l'éloigne d'un `.glb` nu et prévisible. C'est une
ATTÉNUATION, pas une conformité — la décision est celle d'Adrien.

Second point ouvert : le palier de licence. Le palier Personal exige moins de
100 000 $ de revenus dans le numérique sur douze mois. Le jour où ShibuMap
vend (voir docs/superpowers/plans/2026-07-26-comptes-paiements-dons.md), c'est
le palier Professional qui s'applique.
