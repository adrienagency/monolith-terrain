B Comment ça tient ensemble

Le navigateur fait tout le rendu ; le serveur ne sert qu'à trois choses — garder les cartes publiées, encaisser, et envoyer des courriels. C'est ce qui permet à ShibuMap de tenir sur un hébergement à vingt dollars.

D Le chemin de l'argent

Six étapes, dans cet ordre exact. L'ordre n'est pas une commodité : écrire la commande avant d'envoyer le courriel est ce qui fait qu'un paiement ne se perd jamais.

  1. Le visiteur clique « Recevoir le fichier » dans l'application
  2. La caisse (paiement.mjs) demande une session à Stripe — le prix vient du catalogue serveur, jamais du navigateur
  3. Le visiteur paie sur une page hébergée par Stripe : aucune donnée de carte ne touche ce serveur
  4. Stripe rappelle le webhook, dont la signature est vérifiée
  5. La commande est écrite au journal AVANT tout envoi — si le courriel échoue, la vente reste tracée
  6. Resend porte le lien de téléchargement
